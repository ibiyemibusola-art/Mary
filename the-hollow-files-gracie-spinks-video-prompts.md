# The Hollow Files — Episode 1: Gracie Spinks — Video Prompts

## How to use
- These are **image-to-video** prompts. Generate the still first (numbers match the image prompts file), then animate it. This keeps the look consistent.
- Clip length: 5s (or 10s where marked). Slow it to 0.75× in the edit if it feels rushed.
- Only animate the **hero shots** below (25 clips). Every other still gets a simple push-in or pan in the editor.
- Add the **MOTION BLOCK** to every prompt.

**MOTION BLOCK**
```
slow cinematic camera movement, subtle and steady, documentary realism, natural motion only, no sudden cuts, no morphing, no faces turning toward camera, keep colour grade and film grain consistent with the source image, 24fps
```

**Negative (if supported)**
```
fast motion, camera shake, warping, morphing faces, extra limbs, text appearing, flicker, gore, blood
```

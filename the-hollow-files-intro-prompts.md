# The Hollow Files — Video Intro Prompts

**Channel:** THE HOLLOW FILES · **Tagline:** WHAT WAS MISSING WAS ALWAYS THERE
**This case:** GRACIE SPINKS · *The Warning Signs Nobody Connected* · FILE 01
**Colours:** charcoal #121212 · bone white #EDE6DA · oxblood #7A0E12 · amber #C8962E

## How to use
Each intro comes in two versions:
- **A (with text):** a prompt that includes the words, for video tools that render text well, such as Veo, Kling or Runway Gen-4. Expect to try a few times before the spelling comes out clean.
- **B (no text, recommended):** the same scene with no words. Add the titles yourself in your editor (CapCut, Premiere or DaVinci) using the font guide at the bottom. Your text will always be sharp and spelled correctly, and you can reuse the clip for every episode by changing only the case name.

Length: 8–10 seconds each. Aspect: 16:9, 1920×1080, 24fps.

## Text style guide (for the editor)
| Element | Font | Size (1080p) | Colour |
|---|---|---|---|
| THE HOLLOW FILES | Bodoni Moda / Playfair Display, condensed, bold | 110–140px | Bone #EDE6DA |
| Case name (GRACIE SPINKS) | Same serif | 90–120px | Bone, with a thin oxblood underline |
| Subtitle (The Warning Signs Nobody Connected) | Inter or Montserrat, letter-spacing +200 | 32–40px | Bone at 80% |
| FILE 01 | Inter Bold, letter-spacing +300 | 26px | Amber #C8962E |

**Animation:** slow fade-ins with a slight blur-to-sharp, about 0.6s each. No bouncy or spinning effects.
**Sound:** a low drone, then a single heavy "drawer slam" or "stamp" hit when the channel name appears.

## Suggested opening order
Intro 2 (the case) → Intro 3 (channel sting) → first narration line: "A young woman reported a man for stalking her."
